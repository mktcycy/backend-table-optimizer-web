# 後台表格優化工具（網頁版）

將 Excel、Google 試算表、Numbers 或一般網頁表格整理成適合舊式後台富文字編輯器使用的精簡 HTML 表格。

線上使用：[https://mktcycy.github.io/backend-table-optimizer-web/](https://mktcycy.github.io/backend-table-optimizer-web/)

## 功能

- 進站先選「一般表格」或「雙欄圖片」，只顯示目前流程需要的工具
- 貼上試算表或網頁表格，保留格內換行與合併儲存格
- 新增、刪除列欄，支援範圍選取與儲存格合併
- 雙欄圖片使用專用網址欄位，可新增、移除列並調整圖片間距，圖片以 100% 欄寬輸出
- 圖片間距使用實際空白欄與空白列輸出，避免舊式後台預覽清除 `cellspacing` 後讓圖片貼在一起
- 支援拖曳欄標題調整每欄比例，也可輸入百分比、依內容適寬或平均分配
- 表格總寬度支援固定像素與 100% 滿版輸出
- 複製結果除強制比例與舊式數字欄寬外，也會加入透明寬度支撐，避免 BBIN 等編輯器清除樣式後變成均寬
- 自訂表格寬度、顏色、字級、對齊與間距
- 長分隔線與連續文字會限制在欄寬內換行，避免貼到後台後跨欄
- 即時預覽並估算 65,536 Byte 容量限制
- 一鍵複製富文字表格與純文字備援
- 自動將編輯內容保存在目前瀏覽器的 `localStorage`
- 響應式版面，可在桌機、平板與手機瀏覽器使用

## 使用方式

1. 先選擇「一般表格」或「雙欄圖片」。
2. 貼上試算表資料，或在圖片欄位貼入網址。
3. 視需要展開表格結構工具或進階外觀設定。
4. 確認預覽與 Byte 容量後按複製，回後台貼上。

若要製作雙欄圖片區塊，切換到「雙欄圖片」後，在左圖與右圖欄位貼入 `http://` 或 `https://` 圖片網址。預覽會立即顯示圖片，複製結果中的每張圖片都會固定為所在欄位的 100% 寬度。

## 本機開啟

這是無後端、無套件相依的靜態網站。可直接開啟 `index.html`；若瀏覽器限制剪貼簿功能，請用本機伺服器開啟：

```bash
python -m http.server 8000
```

再前往 `http://localhost:8000`。正式部署建議使用 HTTPS（GitHub Pages 預設提供）。

## 隱私

表格內容不會傳送到伺服器，只會儲存在使用者目前瀏覽器的本機儲存空間。清除網站資料會一併移除已保存內容。
